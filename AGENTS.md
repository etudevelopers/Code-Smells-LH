This repository hosts a Samman-style Learning Hour on **Code Smells**: recognizing them, classifying them, and
knowing which refactoring resolves each one.

- `site/` — the Jekyll ([Just the Docs](https://just-the-docs.github.io/just-the-docs/)) site with the Learning
  Hour agenda ([site/index.md](site/index.md)) and supporting explanation pages. Deployed to GitHub Pages by
  `.github/workflows/pages.yml`.
- `board/` — exports and a verbatim content transcript of the companion Miro board, once the board exists.
- `harness/` — a verbatim session-prompt log, kept for traceability of how this repository's content was produced.
