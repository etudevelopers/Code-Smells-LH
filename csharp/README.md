# Learning Hour Template C#

A C# project scaffold for learning hours, configured with .NET and NUnit.

## Run tests

To run the tests for the C# project, from the `csharp` folder run:

```shell
dotnet test
```

## Build

To build the C# project, from the `csharp` folder run:

```shell
dotnet build
```

For more details, see the top-level [README.md](../README.md) file.
